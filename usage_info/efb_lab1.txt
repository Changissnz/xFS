LEMMA: A navigator will not be able to completely traverse an Objective Path Type 
       Directed Implication if this condition holds, throughout its travel: 
    - Navigator's decision-making PRNG fails at node n, and it does not backtrack
        to all the depended nodes of n to solve its activation function. 
    
LEMMA: The characteristic way by which a navigator satisfies the condition specified 
       in the previous lemma is if the navigator's PRNG is a cyclical decider that 
       does not include the entire space of possible decision sequences. There are 
       two primary features a cyclical decider exemplifies itself: 
       -  navigator never takes an out-neighbor subset of node n when it is on it. If 
       navigator has to provide support to any nodes of that out-neighbor subset, there 
       is a non-zero probability navigator can never pass node n. 
       - Another example is when navigator never backtracks back to node n_b when it 
       fails to pass through node n.
