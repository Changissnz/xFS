#------------------------------------------------------------------------------------------------------

The cause of this zero-change has to do with the details of the R-S-T connections belonging to the 
zero-score agents. Consider Agents 0 and 1. 

#------------------------------------------------------------------------------------------------------
## Case: Agent 1 

>>> snbot.rst_to_agent(1,'r')
{0}
>>> snbot.rst_to_agent(0,'t')
set()
>>> snbot.fetch_agent(1).fetch_ports('s')
{4: 0.3273441079927011}
>>> snbot.fetch_agent(1).fetch_ports('t')
{4}

#------------------------------------------------------------------------------------------------------ 
Agent 0 has an R-port to Agent 1. But Agent 0 does not have any transmission activity: no T-ports to 
it. Execution delta is empty. Agent 0 has zero reaction to Agent 1. Agent 1 has an S-port to Agent 4 
and a T-port also to Agent 4. Communication delta nullifies. 

#------------------------------------------------------------------------------------------------------
## Case: Agent 0 

>>> snbot.rst_to_agent(0,'r')
{4, 6}
>>> snbot.fetch_agent(6).communication_delta
defaultdict(<class 'collections.defaultdict'>, {5: defaultdict(<class 'float'>, {1: np.float64(0.0)})})
>>> snbot.fetch_agent(4).communication_delta
defaultdict(<class 'collections.defaultdict'>, {6: defaultdict(<class 'float'>, {1: np.float64(0.0), 6: np.float64(0.0)})})
>>> snbot.fetch_agent(0).communication_delta
defaultdict(<class 'collections.defaultdict'>, {3: defaultdict(<class 'float'>, {4: np.float64(0.0)})})

>>> snbot.fetch_agent(0).fetch_ports('s')
{3: 0.9448233364026919}
>>> snbot.fetch_agent(0).fetch_ports('t')
{4}

#------------------------------------------------------------------------------------------------------

Agent 0 receives no reaction delta from its R-port senders 4 and 6. Agent 0 receives no transmission 
delta from its T-port to Agent 4 on subject Agent 3. 

#------------------------------------------------------------------------------------------------------ 

LEMMA: By the design of the <MutableCEAgentNetwork>, the data structure that <SNBot> is based on, an 
       autonomous agent cannot open or close ports to agents it does not know. Agents that it does not 
       know are ones not found in its maps, "communication_delta" and "execution_delta". The 
       "communication_delta" corresponds to the agents of its initial S-ports and T-ports. The 
       "execution_delta" corresponds to the agents with R-ports to it. 

LEMMA: A consequence of this is that it may not be possible for an autonomous agent to open or close 
       ports for any change to its score. 

#------------------------------------------------------------------------------------------------------

Change line 34 
    snbot = SNBot.from_MutableCEAgentNetwork(mcan,set([]),False)
to 
    snbot = SNBot.from_MutableCEAgentNetwork(mcan,set([0,1,4,5]),False)

Now Agents 0,1,4 and 5 are autonomous. Re-run the code.
